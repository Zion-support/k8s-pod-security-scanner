# K8s Pod Security Scanner

Scan Kubernetes pod specs against Pod Security Standards (restricted/baseline) and get actionable fixes.

**Live app:** https://zion-support.github.io/k8s-pod-security-scanner/

## Features
- Checks pod specs against restricted and baseline Pod Security Standards
- Clear pass/fail per control with remediation hints
- Flags privilege escalation, host namespaces, dangerous capabilities and more
- Exportable report for security reviews and audits
